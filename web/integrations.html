Integrations集成方案

oFoundry exposes an OpenAI-compatible API, so it works seamlessly with any framework that supports the OpenAI protocol. Just change the base_url to your local server.oFoundry 提供 OpenAI 兼容 API，可与任何支持 OpenAI 协议的框架无缝配合。只需将 base_url 指向本地服务器。

OpenAI Python SDK

python 
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:18000/v1", api_key="unused")

response = client.chat.completions.create(
    model="Phi-4-mini-instruct-generic-cpu:5",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
    stream=True,
)
for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

Tip: Point any OpenAI-compatible framework at http://127.0.0.1:18000/v1 and it just works. The api_key can be any non-empty string.提示：将任何 OpenAI 兼容框架指向 http://127.0.0.1:18000/v1 即可使用。api_key 可以是任意非空字符串。

LangChain

python 
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    base_url="http://127.0.0.1:18000/v1",
    api_key="unused",
    model="Phi-4-mini-instruct-generic-cpu:5",
)
response = llm.invoke("Explain ONNX Runtime in one sentence.")

CI / Automated EvaluationCI / 自动化评估

Use oFoundry in CI pipelines for offline model evaluation:在 CI 管线中使用 oFoundry 进行离线模型评估：

bash 
# Start server in background
ofoundry serve --engine ort ./models/phi3-mini-int4 &
sleep 5

# Run your evaluation script against the local endpoint
python eval.py --api-base http://127.0.0.1:18000/v1

# Cleanup
kill %1

Embedding Integrations嵌入集成

The embedding server (ofoundry serve-embed) also follows the OpenAI API and works with any framework that supports custom embedding endpoints:嵌入服务（ofoundry serve-embed）也遵循 OpenAI API，可与任何支持自定义嵌入端点的框架配合使用：

python 
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:18001/v1", api_key="unused")

response = client.embeddings.create(
    model="Qwen3-Embedding-0.6B",
    input=["search query", "document text to match against"],
)
for item in response.data:
    print(f"index={item.index}  dim={len(item.embedding)}")
