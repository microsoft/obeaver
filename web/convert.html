Model Conversion模型转换

Convert Hugging Face models to optimised ONNX format directly from the CLI. This step is required when using the ORT engine with models downloaded from Hugging Face.通过 CLI 直接将 Hugging Face 模型转换为优化的 ONNX 格式。使用 ORT 引擎运行从 Hugging Face 下载的模型时，此步骤是必需的。

Why convert? The ORT engine requires models in ONNX GenAI format (containing genai_config.json + .onnx files). Raw Hugging Face model weights (PyTorch / SafeTensors) cannot be loaded directly. Use obeaver convert to transform them into the correct format.为什么需要转换？ ORT 引擎要求模型为 ONNX GenAI 格式（包含 genai_config.json + .onnx 文件）。原始的 Hugging Face 模型权重（PyTorch / SafeTensors）无法直接加载。使用 obeaver convert 将其转换为正确的格式。

When Do You Need to Convert?何时需要转换？

🟢 Foundry Local Engine🟢 Foundry Local 引擎

No conversion needed. Foundry Local downloads pre-optimised models from the Microsoft catalog automatically. Just pass a catalog alias:无需转换。 Foundry Local 会自动从 Microsoft 目录下载预优化模型。只需传入 catalog alias：

obeaver run Phi-4-mini-instruct-generic-cpu:5

First run will download the model — please wait for it to complete. Run foundry model list to see all available aliases.首次运行会下载模型——请等待下载完成。运行 foundry model list 查看所有可用的模型别名。

🔶 ORT Engine🔶 ORT 引擎

Conversion required. If you download a model from Hugging Face (not a pre-converted ONNX repo), you must convert it before using obeaver run:需要转换。 如果从 Hugging Face 下载模型（非预转换的 ONNX 仓库），必须先转换后才能使用 obeaver run：

obeaver convert Qwen/Qwen3-0.6B
obeaver run --engine ort ./models/Qwen3-0.6B_ONNX_INT4_CPU

Text Model Conversion文本模型转换

For standard text generation models (Qwen, Phi, Llama, etc.), use the default text type. The conversion uses onnxruntime-genai model builder under the hood.对于标准文本生成模型（Qwen、Phi、Llama 等），使用默认的 text 类型。转换底层使用 onnxruntime-genai model builder。

Step-by-step Workflow分步工作流

  1. Convert the model转换模型 Run the convert command with the Hugging Face model name:使用 Hugging Face 模型名称运行转换命令： 
    # INT4 quantized (smallest, fastest on CPU — recommended)
obeaver convert Qwen/Qwen3-0.6B

# FP16 precision
obeaver convert Qwen/Qwen3-0.6B -p fp16

# Custom output directory + extra options
obeaver convert Qwen/Qwen3-0.6B -o ./my_model --extra-options 'shared_embeddings=true'
    The model will be downloaded from Hugging Face, converted, and saved to the output directory (default: ./models/<model>_ONNX_<PRECISION>_<EP>).模型将从 Hugging Face 下载、转换并保存到输出目录（默认：./models/<model>_ONNX_<PRECISION>_<EP>）。
  2. Verify the output验证输出 Check that the output directory contains genai_config.json and .onnx files:检查输出目录是否包含 genai_config.json 和 .onnx 文件： 
    ls ./models/Qwen3-0.6B_ONNX_INT4_CPU/
# → genai_config.json  model.onnx  tokenizer.json  ...
  3. Run with ORT engine使用 ORT 引擎运行 Point oBeaver to the converted model directory:将 oBeaver 指向转换后的模型目录： 
    obeaver run --engine ort ./models/Qwen3-0.6B_ONNX_INT4_CPU

Complete Example: Qwen3-0.6B完整示例：Qwen3-0.6B

bash 
# 1) Convert from Hugging Face to ONNX INT4
obeaver convert Qwen/Qwen3-0.6B

# 2) Chat with the converted model
obeaver run --engine ort ./models/Qwen3-0.6B_ONNX_INT4_CPU --timings

# 3) Or serve as API
obeaver serve --engine ort ./models/Qwen3-0.6B_ONNX_INT4_CPU

Vision-Language (VL) Model Conversion视觉语言 (VL) 模型转换

VL model conversion uses the Olive optimization pipeline from olive-recipes. It exports three sub-models (text decoder, vision encoder, text embedding) and quantizes them to INT4.VL 模型转换使用 Olive 优化管道（参考 olive-recipes）。它会导出三个子模型（文本解码器、视觉编码器、文本嵌入）并将其量化为 INT4。

VL models always use the ORT engine. When a VL model directory is detected (contains vision.onnx), the engine is automatically set to ort — you never need to specify --engine ort manually.VL 模型始终使用 ORT 引擎。 当检测到 VL 模型目录（包含 vision.onnx）时，引擎会自动设置为 ort——无需手动指定 --engine ort。

Step-by-step: Qwen 2.5 VL分步操作：Qwen 2.5 VL

  1. Run the convert command with --type vl使用 --type vl 运行转换命令 
    obeaver convert Qwen/Qwen2.5-VL-3B-Instruct --type vl
    This downloads the model, runs the Olive optimization pipeline, and saves the result to ./models/Qwen2.5-VL-3B-Instruct_VL_ONNX_INT4_CPU.这会下载模型、运行 Olive 优化管道，并将结果保存到 ./models/Qwen2.5-VL-3B-Instruct_VL_ONNX_INT4_CPU。
  2. Verify the output验证输出 The directory should contain vision.onnx, text.onnx, embedding.onnx, plus config files:目录应包含 vision.onnx、text.onnx、embedding.onnx 以及配置文件： 
    ls ./models/Qwen2.5-VL-3B-Instruct_VL_ONNX_INT4_CPU/
# → vision.onnx  text.onnx  embedding.onnx  genai_config.json  ...
  3. Run the VL model运行 VL 模型 
    obeaver run ./models/Qwen2.5-VL-3B-Instruct_VL_ONNX_INT4_CPU

Step-by-step: Qwen 3 VL分步操作：Qwen 3 VL

Qwen 3 VL requires --build-from-source to ensure compatibility with the latest Olive and onnxruntime-genai features. The build process automatically detects your OS and device to select the correct configuration.Qwen 3 VL 需要 --build-from-source 以确保与最新的 Olive 和 onnxruntime-genai 功能兼容。构建过程会自动检测你的操作系统和设备以选择正确的配置。

  1. Run the convert command with --build-from-source使用 --build-from-source 运行转换命令 
    obeaver convert Qwen/Qwen3-VL-2B-Instruct --type vl --build-from-source
    This first builds onnxruntime-genai from source, then runs the Olive pipeline.这会先从源码构建 onnxruntime-genai，然后运行 Olive 管道。
  2. Verify the output验证输出 
    ls ./models/Qwen3-VL-2B-Instruct_VL_ONNX_INT4_CPU/
# → vision.onnx  text.onnx  embedding.onnx  genai_config.json  ...
  3. Run the VL model运行 VL 模型 
    obeaver run ./models/Qwen3-VL-2B-Instruct_VL_ONNX_INT4_CPU

Using Pre-converted Models使用预转换模型

Some models on Hugging Face are already in ONNX GenAI format — no conversion needed. Look for repos tagged onnxruntime-genai:Hugging Face 上的部分模型已经是 ONNX GenAI 格式——无需转换。查找带有 onnxruntime-genai 标签的仓库：

bash 
# Download a pre-converted ONNX model (no conversion needed)
hf download microsoft/Phi-3-mini-4k-instruct-onnx \
  --include "cpu_and_mobile/cpu-int4-rtn-block-32-acc-level-4/*" \
  --local-dir ./models/phi3-mini-int4

# Run directly
obeaver run --engine ort ./models/phi3-mini-int4

How to tell if conversion is needed: Check if the downloaded directory contains genai_config.json and .onnx files. If it contains *.safetensors or pytorch_model.bin instead, you need to convert it first.如何判断是否需要转换：检查下载的目录是否包含 genai_config.json 和 .onnx 文件。如果包含的是 *.safetensors 或 pytorch_model.bin，则需要先转换。

Troubleshooting故障排除

Problem问题Solution解决方案
ModuleNotFoundError: onnxruntime_genai Re-run pip install -e . from the oBeaver project root to install all dependencies.在 oBeaver 项目根目录重新运行 pip install -e . 安装所有依赖。
VL conversion fails with olive not foundVL 转换失败，提示 olive 未找到 Re-run pip install -e . from the oBeaver project root. If the issue persists, try pip install olive-ai manually.在项目根目录重新运行 pip install -e .。如问题仍存在，尝试手动安装 pip install olive-ai。
Qwen 3 VL conversion fails without --build-from-sourceQwen 3 VL 转换失败（未使用 --build-from-source） Add the flag: obeaver convert Qwen/Qwen3-VL-2B-Instruct --type vl --build-from-source添加参数：obeaver convert Qwen/Qwen3-VL-2B-Instruct --type vl --build-from-source
Out of memory during conversion转换过程中内存不足 Close other applications. INT4 quantization requires significant RAM during the conversion process.关闭其他应用程序。INT4 量化在转换过程中需要大量内存。
Model loads but can't generate模型加载成功但无法生成 Verify the output directory contains both genai_config.json and .onnx files. Re-run conversion if incomplete.确认输出目录同时包含 genai_config.json 和 .onnx 文件。如不完整，请重新运行转换。
